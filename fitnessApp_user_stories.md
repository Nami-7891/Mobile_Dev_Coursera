# fitnessApp User Stories

## Exercise 3: Login/Registration Screen
* **Application Registration:** As a new user, I want to register by entering my username, email, and password and clicking the Sign Up button so that I can create a personalized account.
* **Application Login:** As a returning user, I want to input my email and password and click the Login button so that I can access my account.
* **Error Feedback:** As a user, I want to receive clear error messages when clicking Sign Up without entering required details or when entering incorrect login credentials so that I can correct my inputs.
* **Store User Data:** As a user, I want my registration details saved in local storage so that my session data persists between app visits.

---

## Exercise 4: Home Screen
* **Overview Dashboard:** As a user, I want to view an overview of my daily progress (steps walked, calories burned, and water intake) on the home screen so that I can stay motivated and monitor my fitness goals at a glance.
* **Introductory Guide:** As a new user, I want to see a quick introductory guide on the home screen so that I can learn how to log workouts and navigate key features.
* **Quick Actions:** As a user, I want quick shortcuts on the home screen to access my most-used features (e.g., Log Workout, Track Water, View Statistics) so that I can navigate efficiently with minimal clicks.

---

## Exercise 5: Detail Screen
* **Item Details:** As a user, I want detailed information on a selected workout or exercise so that I can make informed decisions about my routine (e.g., viewing target muscle groups, exercise instructions, and burn rate).
* **Save/Share Actions:** As a user, I want to save custom routines or share completed workout summaries on social media from the detail screen so that I can track favorites and engage with others.
* **Related Content:** As a user, I want to view related workouts or alternative exercises on the detail screen so that I can explore new options and keep my routine varied.

---

## Exercise 6: Persistent Data Integration
* **Session Persistence:** As a user, I want my login state saved across app sessions so that I do not have to re-enter my credentials every time I open the app.
* **Preference Persistence:** As a user, I want my custom preferences (such as unit preferences—kg/lbs—or dark mode) saved so that the app retains my preferred environment.
* **Activity Logging:** As an admin, I want user activity and workout history to persist so that the app can generate long-term progress reports and analyze user retention.

---

## Exercise 7: External API Integration
* **Real-time Weather Integration:** As a user, I want real-time weather updates on the home screen via a weather API so that I can decide whether to schedule an outdoor run or an indoor workout.
* **Currency Conversion:** As a user, I want live currency conversion rates displayed when purchasing premium workout plans or gear so that I can make transparent financial choices in my local currency.
* **Map & Location Services:** As a user, I want to view nearby fitness centers, parks, or running trails on an integrated map so that I can easily find convenient locations to exercise.

---

## Exercise 8: Settings Menu
* **Global Access:** As a user, I want to access the settings menu from any screen so that I can adjust my app configuration whenever needed.
* **Categorized Sections:** As a user, I want settings logically grouped into clear categories (e.g., Profile, Notifications, Data Sync) so that I can quickly locate specific options.
* **Admin Controls:** As an admin, I want the ability to enable or disable specific feature toggles in user settings so that I can ensure platform security and regulatory compliance.

---

## Exercise 9: Settings Screen
* **Appearance Customization:** As a user, I want an option to enable dark mode under the Appearance settings so that I can reduce eye strain during nighttime or low-light usage.
* **Notification Preferences:** As a user, I want to customize my notification alerts (e.g., toggle workout reminders vs. marketing alerts) so that I only receive relevant updates.
* **Account Security Update:** As a user, I want to update my email address and password within the settings screen so that I can keep my personal account secure.

---

## Exercise 10: Notifications
* **Daily Reminders:** As a user, I want to receive a daily push notification at a scheduled time (e.g., 9 AM) so that I stay consistent with my planned workouts and habit tracking.
* **Feature Updates:** As a user, I want to receive notifications about new fitness modules or features so that I can explore fresh content and exercises.
* **Promotional Control:** As a user, I want the ability to disable promotional alerts while retaining transactional or reminder updates so that my notification feed remains relevant.
* **Targeted Broadcasts:** As an admin, I want to send targeted notifications to specific user groups (e.g., users who completed a beginner module) so that I can promote relevant advanced training programs.
